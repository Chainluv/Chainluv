# The Great AI Boom: blog + YouTube video kit

| File | What it is |
|---|---|
| `blog.md` | Blog post, ready to paste into WordPress/Ghost/Substack/Medium (upload the `charts/` images with it) |
| `narration.txt` | Voiceover script for the video (`##` lines are chapter markers, not read aloud) |
| `video-plan.md` | Where to get footage/music, shot list per chapter, voiceover tips, caption upload steps, description template |
| `captions/captions.en.srt` | Caption file for YouTube or your editor (separate file, not burned in) |
| `captions/captions.en.vtt` | Same captions in WebVTT, for web video players |
| `captions/transcript.txt` | Plain transcript; upload to YouTube "without timing" for auto-sync |
| `captions/youtube-chapters.txt` | Chapter timestamps for the description |
| `charts/` | 1920×1080 chart frames for the video and the blog |
| `draft/voiceover-draft.mp3` | Rough-draft AI voiceover (13:38). Non-commercial voice license: use for timing only, not the published video |
| `draft/rough-cut.mp4` | Rough-cut video: title cards + charts over the draft voice, captions as a switchable track (not burned in) |
| `draft/captions-draft.en.srt` / `.vtt` | Captions timed exactly to the draft voice |
| `draft/chapters-draft.txt` | Chapter timestamps matching the draft voice |
| `tools/` | Scripts that regenerate the captions, charts, draft voice, and rough cut |

Note: the original draft's P/E example said Company A returns −52% and Company B +205%. With 25% annual earnings growth for 5 years, the correct figures are about **−5%** and **+281%**. Both the blog and narration use the corrected numbers.
